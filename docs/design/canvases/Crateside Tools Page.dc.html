Partners becomes Tools

The tab is renamed Tools. Each tool gets its own sub-tab and address, because they're used one at a time, mid-mashup. A key chosen in one tool carries over to the next. A third tool is one more sub-tab. Re-Pitch is its own tool because it answers a different question (what tempo, not what key). 2a shows the alternative: a Re-Pitch column inside Partners' table.

This earns its place because warped BPMs are often non-whole (95.41). Elsewhere crateside shows them rounded, so the user can't read them off the Tracks page. 2aAlternative · Re-Pitch inside Partners' table

An optional Source BPM adds one column: what the arrangement would be if the source were re-pitched to each partner key (Score gives way for it). It answers a real question, can I re-pitch my way to that partner? But it only covers shifts that land on a partner, and it hides the plain ±n ladder a nightcore edit starts from. So it's a possible later addition to Partners, not a substitute for 1b. Recommended: build 1b now; add this column only if the user asks for it.
