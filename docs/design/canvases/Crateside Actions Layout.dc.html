One side stack, mounted in the row and in the rail

The row's right column (340px) and Track details' rail (19rem) become the same thing: a stack of labeled groups in one fixed order. Tags leave the top of the row, so the samples start at the top. Status sits on its own line under a label; the label's line carries the one action. Destructive acts go last, under a rule, with the source they would replace.

A group with nothing to say is not drawn, label included. Finding stays full width above everything in the row and above the columns on Track details. Change what is cut / Add a source / Adopt a file stay in StemList, beside the samples they change.
