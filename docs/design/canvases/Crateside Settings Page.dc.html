Settings: one row per setting, the control beside its name

Today the page reads as an essay with controls tucked between paragraphs, and Removing from the playlist mixes a switch, an account, a destructive action and a failure list in one run of prose. Here each setting is a row: name and a one-line gist on the left, the control on the right, and a status line under the control. The long explanations shrink to one sentence each; the arithmetic becomes a number. Checkboxes and the interval select become a row of the existing .pill chips (.pill.off, the chosen one .pill.on.plain), so a choice is one click and visible at a glance. Items marked new are new settings, accepted.
