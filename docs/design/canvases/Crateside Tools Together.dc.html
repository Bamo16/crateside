Tools on one page, sharing a selected track

The page reads left to right in the order the user works: the selected track, then Re-Pitch (pick a shift), then Partners, which works from the key that shift lands on and says so. Partners groups its keys by relationship: mixes as is and a shift away. A Camelot wheel beside it draws the same groups, so relationships past relative major and minor can be read at a glance. One click flips Partners to the relative key. Re-Pitch folds to one line.

1cA third tool, later
Working on Re-Pitch ▾ Third tool ▾ Partners + wheel

A tool joins as a foldable column with Re-Pitch's anatomy: a head with ▾, a one-line lead, its controls, its table, a hint. It reads the selected track. If it changes the key or BPM Partners works from, it goes to the left of Partners and the basis line names it ("−1 from Re-Pitch, then …"). If it doesn't, it goes to the right of the wheel. Partners never folds: it is what the page is for. Folded, a tool is one dashed summary line above Partners, stacked in column order. Past four columns at 2560px, the rightmost column wraps under Partners.
